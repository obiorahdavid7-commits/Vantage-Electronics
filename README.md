# Vantage Electronics - Executive Sales Performance Dashboard

Power BI dashboard analyzing **N695.98M Revenue** across 1200 orders, 5 regions, 19 cities, 10 sales reps.

Live Demo: 3-page Power BI report (screenshots below)

## Key Findings
- **Revenue Concentration:** Marketplace N206M (30% of total) leads, Reseller N43M lags - 4.8x gap
- **Profit Crash:** Feb N31M peak to Dec N8M = 74% Q4 drop
- **COGS Outlier:** Wale Ogundipe N60M vs Precious Etim N36M - needs audit
- **Quantity Leader:** Uyo 267 units, South West 1.3K dominates
- **Channel Fix:** In-Store 1001 units vs Reseller 226 units
